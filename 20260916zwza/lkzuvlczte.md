# 枣庄市妇幼保健院党员干部到联创社区“双报到” 助力全国文明城市创建

> 更新时间：2026-09-16 (UTC+8)

为进一步贯彻落实全市机关企事业单位创建全国文明城市推进会议精神，充分发挥医院各党支部战斗堡垒和党员先锋模范作用，不断深化“双报到”工作，助力全国文明城市创建，9月23日，枣庄市妇幼保健院组织各党支部党员前往薛城区陶庄镇联创社区开展“双报到”助力全国文明城市创建志愿服务活动，服务内容包括开展政策宣讲、物资捐赠、健康义诊、卫生整治、文明劝导以及座谈交流等。院党委书记周波、党委副书记赵燕及各党支部党员代表参加活动。本次活动同时邀请市政协妇联界别领导共同参与。

活动伊始，枣庄市妇幼保健院党委书记周波在联创社区居委会会议室开展了创建全国文明城市宣讲，传达学习了我市创建全国文明城市工作推进大会精神。党员代表向社区群众、沿街商户等讲解发放了《枣庄市民文明手册》《争创文明城 共建新枣庄——致全体市民的一封信》等创建宣传资料，同时在社区居委会公告栏等处张贴了《争创文明城 共建新枣庄——致全体市民的一封信》海报。随后，枣庄市妇幼保健院联合市妇联向联创社区党支部捐赠了医用外科口罩、一次性防护手套、洗手液、酒精等防疫物资以及党建书籍、党员学习笔记本等。

活动中，党员同志们佩戴党徽、身穿统一志愿者服装，带上清扫工具，与联创社区党支部党员代表一起走上街头、深入社区共同清理整治社区卫生，对社区道路、公共区域、卫生死角等进行重点清扫，并向社区居民宣传垃圾分类知识，为居民打造舒适、整洁的社区环境。

    同时，市妇联与我院各党支部内科、外科、眼科、耳鼻喉科、口腔科、中医科、妇科等党员专家团队联合在联创社区居委会现场开展了健康义诊活动，对前来咨询就诊的社区居民耐心询问身体状况，为他们提供专业的诊疗服务，并告知常见疾病的防治知识，指导居民合理膳食、规范用药。本次义诊共服务社区居民100余人次，发放健康宣传资料280余份。

    活动最后，院党委书记周波、党委副书记赵燕与联创社区党支部和社区干部群众代表就共驻共建项目进行了座谈交流，双方围绕社区及居民需求，沟通确定了下一步“双报到”工作共驻共建项目，不断推进“双报到”活动走深走实。

此次志愿服务活动，充分发挥了枣庄市妇幼保健院党员干部的先锋模范作用，激发了党员干部为民服务的工作热情，不仅深化了“双报到”工作，强化了与社区的协调联动，同时拉近了和广大群众的距离，让社区群众在家门口享受到了优质的医疗健康服务，受到了社区居民的一致好评。周波书记表示，今后枣庄市妇幼保健院将以“双报到”活动为抓手，继续加强与社区的沟通联系，定期开展志愿服务活动，积极为群众办实事、做好事、解难题，把健康服务送到百姓家门口，提升社区居民的健康素养，为文明枣庄助力。
